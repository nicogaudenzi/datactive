Datactive Help

Quick guides for each workspace.

1. Import Data

  1. Upload a CSV or Excel workbook, or enter a direct URL to a CSV file.
  2. For workbooks with multiple sheets, choose the worksheet you want to import.
  3. Imported values are kept as-is; review and clean them in Profile / Prepare.

2. Profile / Prepare

  1. Start with Column Profiles to inspect types, distributions, and example values.
  2. Open Data-quality findings to investigate missing, inconsistent, or suspicious values.
  3. Use Cleaning Transformations to preview and apply cleanup steps; inspect affected rows when available.

3. Annotate

  1. Select a column and add a description or correct its inferred type and role.
  2. Use geographic roles for columns that represent places or regions.
  3. Annotations describe how Datactive interprets a column; they do not rewrite the source values.

4. Maps

  1. Annotate a column with a geographic role to enable Maps.
  2. Choose the map and explicitly match values in your data to its regions.
  3. Use a mapped geographic column when creating a choropleth chart in Dashboard.

5. Dashboard

  1. Add charts and select the dimensions, measures, and aggregation appropriate to each chart.
  2. Move and resize charts; use chart interactions and the Filters / Ranges panels to explore subsets of the data.
  3. Use the × action to clear filters. Export Interrogation to save a project file, or Import Interrogation to load one.

About Datactive

Interrogate your data

Datactive is a browser-based workspace for understanding datasets, preparing messy data, and exploring patterns through interactive visualizations. Your imported data is processed locally in your browser.

Features

  • Import CSV files, Excel workbooks, and CSV data from direct URLs.
  • Profile columns and inspect data-quality findings and row previews.
  • Preview and apply data-cleaning transformations.
  • Annotate columns with descriptions, types, roles, and geographic metadata.
  • Map data values to geographic regions and build choropleth charts.
  • Create interactive charts and tables with shared filters.
  • Arrange dashboard widgets and export or import an interrogation project.
